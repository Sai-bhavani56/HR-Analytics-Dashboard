# HR Analytics Dashboard

## Overview
This project is an interactive HR Analytics Dashboard developed using Power BI. It provides insights into employee demographics, attrition, salary, job roles, and department-wise analysis.

## Features
- Total Employees
- Attrition Count
- Attrition Rate
- Average Monthly Income
- Average Age
- Department-wise Attrition
- Gender Distribution
- Job Role Analysis
- Education Field Analysis
- Overtime vs Attrition
- Interactive Slicers

## Tools Used
- Power BI
- Power Query
- DAX
- Microsoft Excel

## Skills Demonstrated
- Data Cleaning
- Data Visualization
- DAX Measures
- Dashboard Design
- HR Data Analysis
